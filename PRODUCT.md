# Product

## Register

product

## Users and purpose

Flutter practical coursework. Reproduce the teaching example supplied by the user:
https://github.com/mhddzakwan/IKLC-anime-verse (reference commit ce20c72).
The app demonstrates sign-in, sign-up, anime browsing, details, favorites and profile navigation with dummy data.

## Design direction

Match the reference's visual identity, copy, assets and screen structure. Keep the Urbanist font, blue gradient and existing components. Do not introduce an independent redesign or backend features absent from the example.

## Implementation principles

- Preserve the reference's appearance and teaching structure.
- Adapt dependency versions to the locally installed Flutter SDK.
- Fix compile errors, layout overflows and navigation failures found during verification.
- Keep demo-only authentication and placeholder actions clearly documented.

## Accessibility

Retain Flutter's native text inputs, scrolling and buttons. Verify mobile layouts and keyboard use; no additional accessibility target was specified.
